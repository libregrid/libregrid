# @libregrid/columns-tool-panel

Native DOM columns tool panel and column chooser for AG Grid Community.

Register `ColumnsToolPanelModule` alongside `EnterpriseCoreModule` and
`SideBarModule`. See the repository README for usage, compatibility, and
attribution details.
