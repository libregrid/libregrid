# @libregrid/angular

Angular signal ergonomics for LibreGrid: register modules declaratively with
`provideLibreGrid(...)`, mirror grid state into `Signal`s with
`createGridApiSignals(...)`, and build `GridOptions`/column definitions
with the typed `defineGridOptions` and `createColumnDefs` helpers.

LibreGrid is an independent open-source project and is not affiliated with AG Grid Ltd.
