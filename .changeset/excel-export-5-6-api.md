Add the Excel export API (Phase 5.6): `exportDataAsExcel`, `getDataAsExcel`, `getSheetDataForExcel`, `exportMultipleSheetsAsExcel` and `getMultipleSheetsAsExcel`, with `fileName`, `sheetName`, `mimeType` and `activeSheetIndex`. The grid extraction handles grouped rows, styles from `cellClass`/`cellClassRules`, and multi-sheet round-trips.
